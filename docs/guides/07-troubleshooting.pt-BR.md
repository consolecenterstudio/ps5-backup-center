# Resolver problemas

TV / Web: **Tarefas / Diagnóstico e sobre**.

Se houver interrupção, reconecte o mesmo destino e examine a tarefa existente antes de criar outra. Não apague arquivos parciais nem renomeie pastas para forçar uma nova tentativa. Mantenha uma cópia independente dos dados importantes.

Se desconectar, confira console, motor e endereço atual; examine a tarefa antes de repetir. Não publique códigos ou tokens nem exponha a porta local à Internet.

Se o resultado não for o esperado, pare de jogar para evitar novos salvamentos automáticos. Localize a cópia de segurança e a versão original antes de restaurar novamente. A adaptação dos identificadores não converte partidas incompatíveis entre jogos, regiões ou gerações.
