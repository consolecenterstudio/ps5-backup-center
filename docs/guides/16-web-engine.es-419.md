# Usar el navegador y el motor

La interfaz de TV y el navegador son clientes del mismo motor. Cerrar una interfaz no detiene por sí solo el motor; apagar la consola es diferente.

## Dónde encontrarlo

TV / Web: **Ajustes → Dispositivos → Biblioteca → Tareas**.

## Pasos

1. Lee en la consola la dirección y el código actuales de asociación. Abre esa dirección en la red local, introduce el código de seis cifras y un nombre reconocible. La asociación concede acceso a datos y órdenes.
2. Abre biblioteca y tareas. Revisa destino y alcance antes de iniciar una operación y comprueba el resultado final. Volver a abrir un navegador ya asociado puede conservar el acceso.

## Si se interrumpe

Si se desconecta, comprueba consola, motor y dirección actual; revisa la tarea antes de repetir. No publiques códigos o tokens ni expongas el puerto local a Internet.
