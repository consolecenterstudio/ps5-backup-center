# Para programadores

TV / Web: **Diagnóstico e acerca de / Agradecimentos**.

O motor serve a API e o site e gere inventário, cópias e tarefas persistentes; TV e navegador são clientes. Consulte CONTRIBUTING para compilar com as ferramentas atuais. Uma pré-visualização no Mac não é um teste na consola. Preserve parâmetros de tradução e confirme textos longos, CJK e árabe. A referência detalhada da API é documentação separada.
