# Emulators and ROMs

Keep ROMs, configurations, saves and states distinct.

## Where to find it

TV: Settings › Sources and emulators; Library. Use L1/R1 for tabs; open the gear for Settings.

Web: the corresponding spaces in the paired browser navigation; use buttons and checkboxes.

## Steps

1. Inspect detected emulator sources. Use the catalogue actually installed rather than assuming every emulator has identical save support.
2. Open a source to review ROM folders, settings file and save location; choose folders with the browser. Back to automatic restores detection.
3. Filter Library by emulator, open a ROM and inspect its available components. Select ROM, save, state or configuration according to the intended backup.

4. For Switch profiles, check the matching Eden / ProsperoEden profile before a transfer. Review Tasks after completion.

## Safety and attention

Close the affected game or app before restoring, replacing or moving it. Check account, direction and destination; read confirmations and keep an independent copy of important data. Verification and safety copies reduce risk without providing an absolute guarantee.
