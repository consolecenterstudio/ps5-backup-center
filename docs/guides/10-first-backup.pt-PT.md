# Criar e verificar uma cópia de segurança

Uma cópia guardada não é a partida ativa e não inclui necessariamente o jogo. Escolha os componentes que pretende proteger.

## Onde encontrar

TV / Web: **Biblioteca → Progresso**. **Tarefas**.

## Passos

1. Feche o jogo. Confirme jogador, título, identidade do disco de destino e espaço livre.
2. Abra os detalhes e selecione partida, jogo, DLC, estado ou configuração conforme os componentes disponíveis. Reveja o resumo antes de iniciar.
3. Acompanhe Tarefas até ao resultado final; enviar o pedido não significa concluir a cópia. Leia erros e elementos ignorados.
4. Em Cópias de segurança, abra as versões do jogo e confirme data, localização e componentes da nova cópia.

## Verificar o resultado

A tarefa deve indicar conclusão e a versão esperada deve aparecer. A verificação dos ficheiros não garante que todas as versões futuras do jogo leiam a partida restaurada.

## Se houver interrupção

Se houver interrupção, volte a ligar o mesmo destino e examine a tarefa existente antes de criar outra. Não elimine ficheiros parciais nem mude o nome das pastas para forçar nova tentativa. Mantenha uma cópia independente dos dados importantes.
