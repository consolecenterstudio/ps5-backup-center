# Эмуляторы и ROM

TV / Web: **Настройки / Источники и эмуляторы / Библиотека**.

Проверьте обнаруженные источники и настройки каждого эмулятора. Уточните папки ROM, файл настроек и сохранения; автоматический режим возвращает обнаружение. В карточке ROM выбирайте только предлагаемые компоненты. ROM, состояние и сохранение игры различаются. Для Switch/Eden проверьте профиль получателя.
