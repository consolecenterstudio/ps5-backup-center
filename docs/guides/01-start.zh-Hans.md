# 开始使用

TV / Web: **设置 / 设备**.

1. 在电视上打开设置 → 设备，查看显示的地址和六位配对码。使用同一网络的电脑或手机。

2. 打开自己主机显示的地址，输入当前配对码和易识别的设备名称，然后选择配对。引擎重启会更换配对码，已配对设备仍保留配对。

3. 打开资料库，按内容、模拟器或位置筛选，或搜索标题。操作前打开详情卡，检查可用组件和目标位置。

4. 在任务中查看进度和结果。关闭网页或电视界面不同于停止引擎或关闭主机。

连接失败时检查当前地址、主机、引擎及网络。缺少确认不代表成功。公开求助时不要发布配对码、令牌、账户标识或私人网络地址。
