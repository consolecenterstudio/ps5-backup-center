# 게임과 전송

TV / Web: **전송 / 작업**.

복사는 원본을 남기고 이동은 대상 검증 후 원본을 삭제합니다. 압축만으로 현재 저장 데이터가 보호되지는 않습니다.

두 콘솔에서 게임을 종료합니다. 출발지와 목적지를 따로 선택하고 공간, 구성 요소, 형식, 시스템, SDK와 백포트 호환성을 확인합니다.

확인 전에 수신 디스크와 계정을 점검합니다. 검증 및 설치가 끝날 때까지 기다립니다. 복사 100%가 모든 단계의 완료는 아닙니다.

수신 라이브러리를 새로 고치고 적절할 때 실행을 시험합니다. 이동 실패 시 원본을 수동 삭제하지 마세요. 콘솔 전체 복원은 별도의 예정 기능입니다.
