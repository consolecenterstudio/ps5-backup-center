# 브라우저와 백그라운드 엔진 사용

TV와 브라우저는 같은 엔진의 클라이언트입니다. 화면을 닫아도 엔진이 자동 종료되지는 않습니다. 콘솔 전원을 끄는 것과는 다릅니다.

## 메뉴 위치

TV / Web: **설정 → 기기 → 라이브러리 → 작업**.

## 단계

1. 콘솔의 현재 주소와 페어링 코드를 확인합니다. 같은 로컬 네트워크에서 주소를 열고 6자리 코드와 알아보기 쉬운 이름을 입력합니다. 페어링은 데이터와 명령 접근을 허용합니다.
2. 라이브러리와 작업을 엽니다. 실행 전에 대상과 범위를 확인하고 이후 최종 결과를 확인합니다. 이미 페어링된 브라우저는 접근을 유지할 수 있습니다.

## 중단된 경우

연결이 끊기면 재시도 전에 콘솔, 엔진, 현재 주소와 기존 작업을 확인합니다. 코드나 토큰을 공개하거나 로컬 포트를 인터넷에 노출하지 마세요.
