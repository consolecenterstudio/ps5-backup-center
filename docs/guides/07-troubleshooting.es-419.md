# Resolver problemas

TV / Web: **Tareas / Diagnóstico y acerca de**.

Si se interrumpe, vuelve a conectar el mismo destino y revisa la tarea existente antes de crear otra. No borres archivos parciales ni renombres carpetas para forzar un reintento. Conserva una copia independiente de los datos importantes.

Si se desconecta, comprueba consola, motor y dirección actual; revisa la tarea antes de repetir. No publiques códigos o tokens ni expongas el puerto local a Internet.

Si el resultado no es el esperado, deja de jugar para evitar nuevas escrituras automáticas. Localiza la copia de seguridad y la versión original antes de restaurar de nuevo. La adaptación de identificadores no convierte partidas incompatibles entre juegos, regiones o generaciones.
