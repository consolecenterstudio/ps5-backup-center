# Compare copies and clean up duplicates

## What it is for

Keep useful versions while avoiding multiple identical copies on the same storage. A content fingerprint identifies identical data; the date alone cannot tell which copy contains the most advanced playthrough.

## Where to find it

TV: **Saves**, choose the game and **All versions**. Web: **Saves**, choose the same game and open its versions. On TV, L2 selects copies and Options opens actions for the selection; on the web use checkboxes and the action menu.

## Understand the list

- Location tells you where the copy is stored.
- Different content letters distinguish different contents in this comparison; they are not a ranking from best to worst.
- Progress and play time depend on what the game records and what can be read. A missing value is not evidence of an empty save.
- Protection and account indicators matter before any cleanup. A copy belonging to another player is not a spare version of your own progress.

## Step by step

1. Open the versions and review every storage location, scrolling to the bottom.
2. Request content comparison when available; let the background comparison finish with the game closed.
3. Separate identical copies from genuinely different progress. Decide which versions you want to keep before choosing cleanup.
4. Protect the versions you want preserved. Keeping a recent set of versions is not the same as keeping every distinct playthrough.
5. Open the cleanup proposal and inspect each selected copy. Check account, storage, protected versions and the copies that will remain.
6. Cancel if the proposal does not match your intention. To accept deletion, read the confirmation and complete the requested five-second hold.
7. Reopen the versions and inspect the trash where supported. Check the displayed recovery period; local trash uses 30 days. Do not assume the same recovery is available for every remote storage operation.

## What to avoid

Do not delete solely because two copies have the same timestamp. Do not remove the last independent copy of a distinct progress state. NAS-copy trash is future work; do not treat NAS deletion as recoverable through a local trash.
