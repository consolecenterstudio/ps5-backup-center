# 還原選定的存檔

還原會將已儲存的副本寫入所選帳戶的目前遊戲進度。它不會安裝遊戲，也不是整台主機還原。

## 入口

TV / Web: **存檔 → 所有版本 → 還原**. **工作**.

## 操作步驟

1. 關閉遊戲並保留目前進度的獨立副本。依內容和進度比較版本，不要只看日期。
2. 開啟所選副本並選擇還原。即使使用者名稱相似，也要確認接收帳戶。
3. 閱讀驗證結果及替換前進度的安全副本說明。驗證失敗時應停止並記錄訊息；目標不對則取消。
4. 確認後在工作中等待最終結果。檢查接收帳戶的進度，並在適當時進入遊戲驗證。

## 中斷後的處理

結果不符合預期時先停止遊戲，避免新的自動存檔。再次還原前找到安全副本和原始版本。帳戶適配不會轉換不同遊戲、地區或世代間不相容的存檔。
