# 일상적인 백업과 복원

TV / Web: **라이브러리 / 플레이 데이터 / 세이브 데이터 / 작업**.

보관된 사본은 현재 플레이에 사용하는 저장 데이터와 다르며 게임 본체가 반드시 포함되지는 않습니다. 보호할 구성 요소를 선택하세요.

1. 게임을 종료하고 플레이어, 게임, 대상 디스크의 식별 정보와 여유 공간을 확인합니다.
2. 상세 정보에서 제공되는 저장 데이터, 게임, DLC, 상태 저장, 설정 중 필요한 항목을 선택합니다. 시작 전에 요약을 확인합니다.
3. 작업에서 최종 결과까지 확인합니다. 요청을 보냈다고 백업이 완료된 것은 아닙니다. 오류와 건너뛴 항목을 읽습니다.
4. 백업에서 게임의 버전 목록을 열고 새 사본의 날짜, 위치, 구성 요소를 확인합니다.

복원은 보관된 사본을 선택한 계정의 현재 게임 진행 데이터로 되돌립니다. 게임 설치나 콘솔 전체 복원과는 다릅니다.

예상과 다른 결과라면 새로운 자동 저장을 막기 위해 플레이를 멈추세요. 다시 복원하기 전에 안전 사본과 원래 버전을 찾으세요. 계정 조정은 게임, 지역 또는 세대가 다른 호환되지 않는 저장 데이터를 변환하지 않습니다.
