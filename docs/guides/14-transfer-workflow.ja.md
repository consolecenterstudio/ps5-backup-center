# ゲーム全体をコピーまたは移動する

コピーは元を残し、移動は保存先の検証後に元を削除します。圧縮だけでは現在のセーブを保護できません。

## 操作する場所

TV / Web: **転送 → タスク**.

## 手順

1. 両方の本体でゲームを終了します。コピー元と先を別々に選び、容量、項目、形式、システム、SDK、バックポートの互換性を確認します。
2. 確認前に受信ディスクとアカウントを確認します。検証とインストールの完了まで待ちます。コピー100%は全段階の完了ではありません。

## 中断した場合

受信側のライブラリを更新し、適切なときに起動を試します。移動に失敗しても元を手動削除しないでください。本体全体の復元は別の今後の機能です。
