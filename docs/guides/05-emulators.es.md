# Emuladores y ROMs

TV / Web: **Ajustes / Orígenes y emuladores / Biblioteca**.

Revisa las fuentes detectadas y la configuración de cada emulador. Comprueba carpetas de ROMs, archivo de configuración y ubicación de partidas; volver al modo automático restablece la detección. En la ficha de una ROM selecciona solo los componentes ofrecidos. Una ROM, un estado y una partida son distintos. Para Switch/Eden comprueba el perfil receptor.
