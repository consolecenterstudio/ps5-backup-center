# Juegos y transferencias

TV / Web: **Transferencias / Tareas**.

Copiar conserva el origen; mover lo elimina después de verificar el destino. Comprimir el juego no guarda por sí solo la partida activa.

Cierra el juego en ambas consolas. Elige origen y destino por separado, comprueba espacio, componentes y compatibilidad del formato, sistema, SDK y backport.

Revisa disco y cuenta receptores antes de confirmar. Sigue la tarea hasta completar verificación e instalación; un 100 % de copia no significa que todas las fases hayan terminado.

Actualiza la biblioteca receptora y prueba el juego cuando corresponda. Si falla un traslado, no borres el origen manualmente. La restauración completa de consola es una función futura distinta.
