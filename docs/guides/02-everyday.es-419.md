# Copias y restauración diaria

TV / Web: **Biblioteca / Progreso / Partidas guardadas / Tareas**.

Una copia almacenada no es la partida activa ni incluye necesariamente el juego. Selecciona los componentes que quieras proteger.

1. Cierra el juego. Comprueba el jugador, el título, la unidad de destino y el espacio libre.
2. Abre la ficha y selecciona partida, juego, DLC, estado o configuración según los componentes disponibles. Comprueba el resumen antes de iniciar la copia.
3. Sigue Tareas hasta el resultado final; una solicitud enviada no significa que la copia haya terminado. Lee los errores y elementos omitidos.
4. En Copias de seguridad, abre las versiones del juego y comprueba fecha, ubicación y componentes de la nueva copia.

Restaurar convierte una copia almacenada en la partida activa del usuario elegido. No instala el juego ni restaura toda la consola.

Si el resultado no es el esperado, deja de jugar para evitar nuevas escrituras automáticas. Localiza la copia de seguridad y la versión original antes de restaurar de nuevo. La adaptación de identificadores no convierte partidas incompatibles entre juegos, regiones o generaciones.
