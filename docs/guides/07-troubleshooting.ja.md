# トラブルシューティング

TV / Web: **タスク / 診断と情報**.

中断した場合は同じ保存先を再接続し、新しいタスクを作る前に既存のタスクを確認します。再試行を強制するために途中のファイルを削除したりフォルダー名を変えたりしないでください。重要なデータは独立したコピーも保管します。

切断時は本体、エンジン、現在のアドレス、既存のタスクを確認してから再試行します。コードやトークンを公開せず、ローカルポートをインターネットに公開しないでください。

結果が予想と違う場合は、新しい自動セーブを避けるためプレイを止めます。再び復元する前に安全用コピーと元のバージョンを確認してください。アカウントの調整は、異なるゲーム、地域、世代の非互換セーブを変換するものではありません。
