# 올바른 동기화 방식 선택

보관된 사본과 현재 게임 저장 데이터는 다릅니다. 전체 게임은 전송에서 관리합니다. 계획이 빨리 준비된다고 지속적인 자동 동기화가 되는 것은 아닙니다.

## 메뉴 위치

TV / Web: **동기화** → **세이브 데이터 / 현재 플레이 데이터 / 앱 / DLC / 설정**.

## 단계

1. 기기를 선택한 뒤 사본, 현재 저장 데이터, 앱, 설정 또는 DLC를 선택합니다. 적은 수의 명시적인 항목부터 시작합니다.
2. 사본은 게임, 버전, 대상을 확인합니다. 현재 저장 데이터는 양쪽 계정, 방향, 충돌을 확인하고 두 콘솔 모두에서 게임을 종료합니다.
3. 앱은 수신 앱을 종료한 뒤 버전과 지문을 비교합니다. 같은 버전이라도 파일이 다르면 결정이 필요합니다. 사용 가능한 프로필에 따라 설정 범위를 선택합니다.
4. 변경 내용을 읽고 의도한 작업만 확인합니다. 작업 결과를 확인하고 재시도 전에 비교를 새로 고칩니다.

## 추가 정보

NAS는 현재 저장 데이터와 앱의 보관소가 될 수 있지만 게임을 실행하지는 않습니다. DLC와 설정은 PS5 간 작업입니다. Switch/Eden은 게임과 프로필을 확인하고 JKSV 및 ftpd를 준비해야 합니다. Switch로 돌려보낼 때 JKSV 가져오기도 마쳐야 합니다. Switch 간 동기화와 PS5 DLC 설치는 예정된 기능이며 패키지 목록은 설치가 아닙니다.
