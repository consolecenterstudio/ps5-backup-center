# Tworzenie i sprawdzanie kopii zapasowej

Przechowywana kopia nie jest aktywnym zapisem gry i nie musi zawierać samej gry. Wybierz składniki, które chcesz zabezpieczyć.

## Gdzie znaleźć

TV / Web: **Biblioteka → Postępy**. **Zadania**.

## Kroki

1. Zamknij grę. Sprawdź gracza, tytuł, tożsamość dysku docelowego i wolne miejsce.
2. Otwórz szczegóły i wybierz zapis, grę, DLC, stan lub konfigurację spośród dostępnych składników. Przed uruchomieniem sprawdź podsumowanie.
3. Śledź Zadania do wyniku końcowego. Wysłanie żądania nie oznacza ukończenia kopii. Przeczytaj błędy i informacje o pominiętych elementach.
4. W Kopiach zapasowych otwórz wersje gry i sprawdź datę, lokalizację oraz składniki nowej kopii.

## Sprawdzenie wyniku

Zadanie powinno być ukończone, a oczekiwana wersja widoczna. Weryfikacja plików nie gwarantuje, że każda przyszła wersja gry odczyta przywrócony zapis.

## Po przerwaniu

Po przerwaniu ponownie podłącz ten sam nośnik docelowy i sprawdź istniejące zadanie przed utworzeniem nowego. Nie usuwaj częściowych plików ani nie zmieniaj nazw folderów, aby wymusić ponowienie. Zachowaj niezależną kopię ważnych danych.
