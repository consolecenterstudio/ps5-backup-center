# Pierwsze kroki

TV / Web: **Ustawienia / Urządzenia**.

1. Na TV otwórz Ustawienia → Urządzenia. Odczytaj adres i sześciocyfrowy kod. Użyj komputera lub telefonu w tej samej sieci.

2. Otwórz adres własnej konsoli. Wpisz aktualny kod i rozpoznawalną nazwę, potem wybierz parowanie. Kod zmienia się po restarcie silnika; sparowane urządzenia pozostają sparowane.

3. Otwórz Bibliotekę. Filtruj zawartość, emulator lub lokalizację albo wyszukaj tytuł. Przed działaniem sprawdź składniki i cel na karcie.

4. W Zadaniach śledź postęp i wyniki. Zamknięcie strony lub interfejsu TV nie oznacza zatrzymania silnika ani wyłączenia konsoli.

W razie błędu sprawdź aktualny adres, konsolę, silnik i sieć. Brak potwierdzenia nie oznacza sukcesu. Nie publikuj kodów, tokenów, ID kont ani prywatnych adresów w zgłoszeniach.
