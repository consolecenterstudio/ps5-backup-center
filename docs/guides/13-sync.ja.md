# 適切な同期を選ぶ

保存済みのコピーと現在のセーブは別物です。ゲーム全体は転送で扱います。計画の準備が速くても、継続的な自動同期を意味しません。

## 操作する場所

TV / Web: **同期** → **セーブデータ / 現在のプレイデータ / アプリ / DLC / 設定**.

## 手順

1. 機器を選び、コピー、現在のセーブ、アプリ、設定、DLCの種類を選びます。最初は少数の項目を明示的に選択します。
2. コピーではゲーム、バージョン、保存先を確認します。現在のセーブでは両側のアカウント、方向、競合を確認し、両方の本体でゲームを終了します。
3. アプリでは受信側のアプリを終了し、バージョンと指紋を比較します。同じ番号でもファイルが違えば判断が必要です。利用可能なプロファイルに従って設定の範囲を選びます。
4. 変更内容を読み、意図した操作だけを確認します。タスクの結果を確認し、再実行する前に比較を更新します。

## 詳しい情報

NASは現在のセーブやアプリの保管場所になりますが、ゲームを実行しません。DLCと設定はPS5間の操作です。Switch/Edenではゲームとプロファイルを確認し、JKSVとftpdを準備します。Switchへ戻すときはJKSVのインポートも完了してください。Switch同士の同期とPS5 DLCのインストールは今後の予定です。パッケージ一覧はインストールの証拠ではありません。
