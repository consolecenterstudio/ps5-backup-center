# 建立並檢查備份

已儲存的副本不是目前可玩的存檔，也不一定包含遊戲本體。請明確選擇需要保護的元件。

## 入口

TV / Web: **遊戲庫 → 遊戲進度**. **工作**.

## 操作步驟

1. 關閉遊戲，確認玩家、遊戲、目標磁碟的身分及可用空間。
2. 開啟詳細資料，從提供的元件中選擇存檔、遊戲、DLC、即時存檔或設定。開始前檢查摘要。
3. 在工作中等待最終結果。提交請求不等於備份完成，請閱讀錯誤和略過項目。
4. 在備份頁面開啟遊戲的版本清單，檢查新副本的日期、位置和元件。

## 檢查結果

工作應顯示完成，預期版本也應出現在清單中。檔案驗證並不保證遊戲的所有未來版本都能讀取還原後的存檔。

## 中斷後的處理

操作中斷後，重新連接同一目標並先檢查現有工作，再決定是否建立新工作。不要為了強行重試而刪除部分檔案或重新命名資料夾。為重要資料保留獨立副本。
