# 선택한 저장 데이터 복원

복원은 보관된 사본을 선택한 계정의 현재 게임 진행 데이터로 되돌립니다. 게임 설치나 콘솔 전체 복원과는 다릅니다.

## 메뉴 위치

TV / Web: **세이브 데이터 → 모든 버전 → 복원**. **작업**.

## 단계

1. 게임을 종료하고 현재 진행 데이터의 독립된 사본을 보관합니다. 날짜뿐 아니라 내용과 진행 상황을 비교합니다.
2. 선택한 사본을 열고 복원을 선택합니다. 프로필 이름이 비슷해도 수신 계정을 확인합니다.
3. 검증 결과와 교체될 저장 데이터의 안전 사본 안내를 읽습니다. 검증 실패 시 중지하고 메시지를 기록하며 대상이 틀리면 취소합니다.
4. 확인한 뒤 작업의 최종 결과까지 기다립니다. 수신 계정의 진행 상황을 확인하고 적절할 때 게임에서도 확인합니다.

## 중단된 경우

예상과 다른 결과라면 새로운 자동 저장을 막기 위해 플레이를 멈추세요. 다시 복원하기 전에 안전 사본과 원래 버전을 찾으세요. 계정 조정은 게임, 지역 또는 세대가 다른 호환되지 않는 저장 데이터를 변환하지 않습니다.

**복원** · **작업**
