# はじめに

TV / Web: **設定 / デバイス**.

1. TVで設定 → デバイスを開き、表示されたアドレスと6桁のコードを確認します。同じネットワークのPCまたは電話を使います。

2. 自分の本体に表示されたアドレスを開き、現在のコードと分かりやすいデバイス名を入力してペアリングします。エンジンの再起動でコードは変わりますが、登録済みデバイスは保持されます。

3. ライブラリーを開き、内容、エミュレーター、場所で絞り込むかタイトルを検索します。操作前に詳細で構成要素と保存先を確認します。

4. タスクで進捗と結果を確認します。ページやTV画面を閉じることは、エンジン停止や本体電源オフとは別です。

接続できない場合は現在のアドレス、本体、エンジン、ネットワークを確認します。確認がない状態を成功と扱わないでください。公開のサポート依頼にコード、トークン、アカウントID、私有アドレスを載せないでください。
