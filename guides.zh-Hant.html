開始使用

TV / Web: 設定 / 裝置.

  1. 在電視上開啟設定 → 裝置，查看顯示的位址和六位配對碼。使用同一網路的電腦或手機。

  2. 開啟自己主機顯示的位址，輸入目前配對碼和易辨識的裝置名稱，然後選擇配對。引擎重啟會更換配對碼，已配對裝置仍保留配對。

  3. 開啟資料庫，依內容、模擬器或位置篩選，或搜尋標題。操作前開啟詳細資料卡，檢查可用元件和目標位置。

  4. 在任務中查看進度和結果。關閉網頁或電視介面不同於停止引擎或關閉主機。

連線失敗時檢查目前位址、主機、引擎及網路。缺少確認不代表成功。公開求助時不要發布配對碼、權杖、帳戶識別或私人網路位址。

日常備份與還原

TV / Web: 遊戲庫 / 遊戲進度 / 存檔 / 工作.

已儲存的副本不是目前可玩的存檔，也不一定包含遊戲本體。請明確選擇需要保護的元件。

  1. 關閉遊戲，確認玩家、遊戲、目標磁碟的身分及可用空間。
  2. 開啟詳細資料，從提供的元件中選擇存檔、遊戲、DLC、即時存檔或設定。開始前檢查摘要。
  3. 在工作中等待最終結果。提交請求不等於備份完成，請閱讀錯誤和略過項目。
  4. 在備份頁面開啟遊戲的版本清單，檢查新副本的日期、位置和元件。

建立並檢查備份

已儲存的副本不是目前可玩的存檔，也不一定包含遊戲本體。請明確選擇需要保護的元件。

入口

TV / Web: 遊戲庫 → 遊戲進度. 工作.

操作步驟

  1. 關閉遊戲，確認玩家、遊戲、目標磁碟的身分及可用空間。
  2. 開啟詳細資料，從提供的元件中選擇存檔、遊戲、DLC、即時存檔或設定。開始前檢查摘要。
  3. 在工作中等待最終結果。提交請求不等於備份完成，請閱讀錯誤和略過項目。
  4. 在備份頁面開啟遊戲的版本清單，檢查新副本的日期、位置和元件。

檢查結果

工作應顯示完成，預期版本也應出現在清單中。檔案驗證並不保證遊戲的所有未來版本都能讀取還原後的存檔。

中斷後的處理

操作中斷後，重新連接同一目標並先檢查現有工作，再決定是否建立新工作。不要為了強行重試而刪除部分檔案或重新命名資料夾。為重要資料保留獨立副本。

Markdown ↗

比較副本並清理重複項目

日期不能單獨說明哪份進度最前面。內容字母區分不同資料，不代表好壞排名。

入口

TV / Web: 存檔 → 所有版本.

操作步驟

  1. 開啟所有版本，檢查位置、帳戶和保護狀態，在遊戲關閉時等待比較。無法讀取進度並不表示存檔為空。
  2. 檢查每份待刪除與保留的副本。保留重要版本及其他玩家的副本。選擇不對則取消；刪除需要按住確認五秒。

中斷後的處理

在支援的位置查看資源回收筒和期限。本機回收筒為30天；不要假定NAS有相同還原能力。NAS回收筒屬於未來功能。

還原選定的存檔

還原會將已儲存的副本寫入所選帳戶的目前遊戲進度。它不會安裝遊戲，也不是整台主機還原。

入口

TV / Web: 存檔 → 所有版本 → 還原. 工作.

操作步驟

  1. 關閉遊戲並保留目前進度的獨立副本。依內容和進度比較版本，不要只看日期。
  2. 開啟所選副本並選擇還原。即使使用者名稱相似，也要確認接收帳戶。
  3. 閱讀驗證結果及替換前進度的安全副本說明。驗證失敗時應停止並記錄訊息；目標不對則取消。
  4. 確認後在工作中等待最終結果。檢查接收帳戶的進度，並在適當時進入遊戲驗證。

中斷後的處理

結果不符合預期時先停止遊戲，避免新的自動存檔。再次還原前找到安全副本和原始版本。帳戶適配不會轉換不同遊戲、地區或世代間不相容的存檔。

安排備份計畫

計畫重複執行選定的備份設定，不是未來的遊戲關閉時自動同步。

入口

TV / Web: 工作 → 定時排程….

操作步驟

  1. 從工作或遊戲詳細資料開啟計畫編輯器。選擇範本或自訂計畫、名稱、遊戲或規則、元件、目標、時間及保留版本數。
  2. 檢查新遊戲如何納入計畫及目標是否可達。儲存後重新開啟核對。適當時手動執行一次，檢查工作和新副本。

中斷後的處理

暫停計畫與取消一次執行不同。重試前檢查錯誤及既有工作。輪替不能取代獨立副本。

選擇正確的同步方式

已儲存副本與目前遊戲存檔不同。完整遊戲透過傳輸管理。快速準備的計畫不等於持續自動同步。

入口

TV / Web: 同步 → 存檔 / 當前遊戲進度 / App / DLC / 設定.

操作步驟

  1. 先選擇裝置，再選擇副本、目前存檔、應用程式、設定或DLC。先從少量明確選取的項目開始。
  2. 同步副本時檢查遊戲、版本和目標。同步目前存檔時檢查兩端帳戶、方向和衝突，並在兩台主機上關閉遊戲。
  3. 同步應用程式前關閉接收端應用程式，比較版本與指紋。同版本但檔案不同需要作出選擇。依可用設定檔選擇設定範圍。
  4. 閱讀變更，只確認符合意圖的操作。在工作中等待結果，重試前重新整理比較。

更多資訊
