TV / Web: 설정 / 기기.

  1. TV에서 설정 → 기기를 열고 표시된 주소와 6자리 코드를 확인합니다. 같은 네트워크의 컴퓨터나 휴대전화를 사용합니다.

  2. 자기 콘솔에 표시된 주소를 열고 현재 코드와 알아보기 쉬운 기기 이름을 입력한 뒤 페어링합니다. 엔진 재시작 시 코드는 바뀌지만 기존 페어링은 유지됩니다.

  3. 라이브러리에서 내용, 에뮬레이터, 위치를 필터링하거나 제목을 검색합니다. 작업 전에 상세 카드에서 구성 요소와 대상을 확인합니다.

  4. 작업에서 진행 상황과 결과를 확인합니다. 페이지나 TV 화면을 닫는 것은 엔진 중지나 콘솔 종료와 다릅니다.

접속 실패 시 현재 주소, 콘솔, 엔진과 네트워크를 확인합니다. 확인이 없으면 성공으로 간주하지 않습니다. 공개 지원 요청에 코드, 토큰, 계정 ID나 사설 주소를 올리지 않습니다.

메뉴 위치

TV / Web: 라이브러리 → 플레이 데이터. 작업.

단계

  1. 게임을 종료하고 플레이어, 게임, 대상 디스크의 식별 정보와 여유 공간을 확인합니다.

  3. 작업에서 최종 결과까지 확인합니다. 요청을 보냈다고 백업이 완료된 것은 아닙니다. 오류와 건너뛴 항목을 읽습니다.
  4. 백업에서 게임의 버전 목록을 열고 새 사본의 날짜, 위치, 구성 요소를 확인합니다.

결과 확인

작업이 완료되고 예상한 버전이 목록에 나타나야 합니다. 파일 검증이 게임의 모든 미래 버전에서 복원된 저장 데이터를 읽을 수 있음을 보장하지는 않습니다.

사본 비교 및 중복 정리

날짜만으로 가장 앞선 진행 상황을 알 수 없습니다. 내용 문자는 데이터를 구분하며 순위가 아닙니다.

메뉴 위치

TV / Web: 세이브 데이터 → 모든 버전.

단계

  1. 모든 버전을 열고 위치, 계정, 보호 상태를 확인한 뒤 게임을 종료하고 비교를 기다립니다. 진행 상황을 읽을 수 없다고 빈 저장 데이터는 아닙니다.
  2. 삭제 후보와 남길 사본을 하나씩 확인합니다. 중요한 버전과 다른 플레이어의 사본을 보존합니다. 잘못 선택했으면 취소하며 삭제는 5초 동안 눌러 확인합니다.

중단된 경우

지원되는 위치에서 휴지통과 기간을 확인합니다. 로컬 휴지통은 30일이며 NAS에도 같은 복구를 기대하면 안 됩니다. NAS 휴지통은 예정 기능입니다.

선택한 저장 데이터 복원

복원은 보관된 사본을 선택한 계정의 현재 게임 진행 데이터로 되돌립니다. 게임 설치나 콘솔 전체 복원과는 다릅니다.

메뉴 위치

TV / Web: 세이브 데이터 → 모든 버전 → 복원. 작업.

단계

  1. 게임을 종료하고 현재 진행 데이터의 독립된 사본을 보관합니다. 날짜뿐 아니라 내용과 진행 상황을 비교합니다.
  2. 선택한 사본을 열고 복원을 선택합니다. 프로필 이름이 비슷해도 수신 계정을 확인합니다.
  3. 검증 결과와 교체될 저장 데이터의 안전 사본 안내를 읽습니다. 검증 실패 시 중지하고 메시지를 기록하며 대상이 틀리면 취소합니다.
  4. 확인한 뒤 작업의 최종 결과까지 기다립니다. 수신 계정의 진행 상황을 확인하고 적절할 때 게임에서도 확인합니다.
