# Aan de slag

![PS5 Backup Center](assets/brand-preserve.png)

TV / Web: **Instellingen / Apparaten**.

1. Open op de TV Instellingen → Apparaten. Lees het adres en de zescijferige code. Gebruik een computer of telefoon op hetzelfde netwerk.

2. Open het adres van de eigen console. Vul de huidige code en een herkenbare apparaatnaam in en kies Koppelen. De code verandert bij een motorherstart; gekoppelde apparaten blijven gekoppeld.

3. Open Bibliotheek. Filter op inhoud, emulator of locatie of zoek een titel. Controleer onderdelen en doel in de detailweergave voor een handeling.

4. Volg voortgang en resultaten bij Taken. Een pagina of TV-interface sluiten is iets anders dan de motor stoppen of de console uitzetten.

Controleer bij fouten het huidige adres, console, motor en netwerk. Geen bevestiging betekent geen bewezen succes. Publiceer geen codes, tokens, account-ID’s of privéadressen bij een hulpvraag.
