# 문제 해결

![PS5 Backup Center](assets/brand-web.png)

TV / Web: **작업 / 진단 및 정보**.

중단되면 같은 대상을 다시 연결하고 새 작업을 만들기 전에 기존 작업을 확인하세요. 재시도를 강제하려고 부분 파일을 삭제하거나 폴더 이름을 바꾸지 마세요. 중요한 데이터는 독립된 사본도 보관하세요.

연결이 끊기면 재시도 전에 콘솔, 엔진, 현재 주소와 기존 작업을 확인합니다. 코드나 토큰을 공개하거나 로컬 포트를 인터넷에 노출하지 마세요.

예상과 다른 결과라면 새로운 자동 저장을 막기 위해 플레이를 멈추세요. 다시 복원하기 전에 안전 사본과 원래 버전을 찾으세요. 계정 조정은 게임, 지역 또는 세대가 다른 호환되지 않는 저장 데이터를 변환하지 않습니다.
