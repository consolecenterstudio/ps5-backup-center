# 选择正确的同步方式

![PS5 Backup Center](assets/brand-link.png)

已存储副本与当前游戏存档不同。完整游戏通过传输管理。快速准备的计划不等于持续自动同步。

## 入口

TV / Web: **同步** → **存档 / 当前游戏进度 / 应用 / DLC / 设置**.

## 操作步骤

1. 先选择设备，再选择副本、当前存档、应用、设置或DLC。先从少量明确选择的项目开始。
2. 同步副本时检查游戏、版本和目标。同步当前存档时检查两端账户、方向和冲突，并在两台主机上关闭游戏。
3. 同步应用前关闭接收端应用，比较版本与指纹。同版本但文件不同需要作出选择。根据可用应用配置选择设置范围。
4. 阅读变更，仅确认符合意图的操作。在任务中等待结果，重试前刷新比较。

## 更多信息

NAS可作为当前存档和应用的存储仓库，但不会运行游戏。DLC和设置仍是PS5之间的流程。Switch/Eden需确认游戏与配置文件，准备JKSV和ftpd，传回Switch后还要完成JKSV导入。Switch ↔ Switch和PS5 DLC安装属于未来计划；发现软件包不等于安装。
