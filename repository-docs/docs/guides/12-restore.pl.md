# Przywracanie wybranego zapisu gry

![PS5 Backup Center](assets/brand-preserve.png)

Przywrócenie zamienia przechowywaną kopię w aktywny zapis wybranego konta. Nie instaluje gry ani nie przywraca całej konsoli.

## Gdzie znaleźć

TV / Web: **Zapisy → Wszystkie wersje → Przywróć**. **Zadania**.

## Kroki

1. Zamknij grę i zachowaj niezależną kopię obecnego zapisu. Porównuj wersje według zawartości i postępów, nie tylko daty.
2. Otwórz wybraną kopię i wybierz przywracanie. Sprawdź konto docelowe nawet przy podobnych nazwach profili.
3. Przeczytaj wynik weryfikacji i informację o kopii bezpieczeństwa zastępowanego zapisu. Jeśli weryfikacja się nie powiedzie, zatrzymaj się i zanotuj komunikat; anuluj przy błędnym celu.
4. Potwierdź i śledź zadanie do końcowego wyniku. Sprawdź postępy konta odbiorcy, a następnie, gdy to odpowiednie, otwórz je w grze.

## Po przerwaniu

Jeśli wynik jest nieoczekiwany, przerwij grę, aby uniknąć nowych automatycznych zapisów. Przed kolejnym przywróceniem znajdź kopię bezpieczeństwa i wersję oryginalną. Dopasowanie konta nie konwertuje niezgodnych zapisów między grami, regionami ani generacjami.
