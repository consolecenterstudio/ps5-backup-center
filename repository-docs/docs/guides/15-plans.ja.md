# バックアップ計画を設定する

![PS5 Backup Center](assets/brand-organize.png)

計画は選んだバックアップ設定を繰り返します。ゲーム終了時の自動同期という今後の機能とは別です。

## 操作する場所

TV / Web: **タスク → スケジュールされたプラン…**.

## 手順

1. タスクかゲームの詳細から計画を開きます。テンプレートか独自計画、名前、ゲームか規則、項目、保存先、時刻、保持数を選びます。
2. 新しいゲームの追加方法と保存先の接続を確認します。保存後に開き直して確認し、必要なら一度実行してタスクと新しいコピーを確認します。

## 中断した場合

計画の一時停止と一回の実行の中止は別です。再実行前にエラーと既存タスクを確認してください。世代管理は独立したコピーの代わりにはなりません。
