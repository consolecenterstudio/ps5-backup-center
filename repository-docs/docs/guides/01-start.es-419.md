# Primeros pasos

![PS5 Backup Center](assets/brand-preserve.png)

TV / Web: **Ajustes / Dispositivos**.

1. En la TV, abrir Ajustes → Dispositivos. Consultar la dirección y el código de seis dígitos mostrados. Usar un ordenador o teléfono de la misma red.

2. Abrir la dirección de la propia consola. Introducir el código actual y un nombre reconocible, y elegir Vincular. El código cambia al reiniciar el motor; los dispositivos vinculados siguen vinculados.

3. Abrir Biblioteca. Filtrar por contenido, emulador o ubicación, o buscar un título. Abrir una ficha y revisar componentes y destino antes de cualquier operación.

4. Usar Tareas para seguir progreso y resultados. Cerrar una página o la interfaz de TV no equivale a detener el motor o apagar la consola.

Si falla, revisar dirección actual, consola, motor y red. La falta de confirmación no es éxito. No publicar códigos, tokens, identificadores de cuenta ni direcciones privadas al pedir ayuda.
