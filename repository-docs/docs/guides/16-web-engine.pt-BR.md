# Usar o navegador e o motor

![PS5 Backup Center](assets/brand-web.png)

A interface de TV e o navegador são clientes do mesmo motor. Fechar uma interface não para o motor por si só; desligar o console é diferente.

## Onde encontrar

TV / Web: **Configurações → Dispositivos → Biblioteca → Tarefas**.

## Etapas

1. Leia na console o endereço e código atuais de associação. Abra o endereço na rede local e informe o código de seis dígitos e um nome reconhecível. A associação concede acesso a dados e comandos.
2. Abra biblioteca e tarefas. Confira destino e escopo antes de iniciar uma operação e verifique o resultado final. Um navegador já associado pode manter o acesso ao reabrir.

## Se houver interrupção

Se desconectar, confira console, motor e endereço atual; examine a tarefa antes de repetir. Não publique códigos ou tokens nem exponha a porta local à Internet.
