# Browser und Hintergrund-Engine nutzen

![PS5 Backup Center](assets/brand-web.png)

TV-Oberfläche und Browser sind Clients derselben Engine. Eine Oberfläche zu schließen stoppt die Engine nicht automatisch; die Konsole auszuschalten ist etwas anderes.

## Wo du es findest

TV / Web: **Einstellungen → Geräte → Bibliothek → Aufgaben**.

## Schritte

1. Lies aktuelle Adresse und Kopplungscode auf der Konsole ab. Öffne die Adresse im lokalen Netz und gib den sechsstelligen Code und einen erkennbaren Namen ein. Die Kopplung erlaubt Zugriff auf Daten und Befehle.
2. Öffne Bibliothek und Aufgaben. Prüfe Ziel und Umfang vor einem Auftrag und lies dessen Endergebnis. Ein gekoppelter Browser kann seinen Zugang behalten.

## Bei einer Unterbrechung

Prüfe bei Abbruch Konsole, Engine und aktuelle Adresse sowie den bestehenden Auftrag vor erneutem Start. Veröffentliche keine Codes oder Tokens und leite den lokalen Port nicht ins Internet weiter.
