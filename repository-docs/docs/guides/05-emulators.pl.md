# Emulatory i ROM-y

![PS5 Backup Center](assets/brand-web.png)

TV / Web: **Ustawienia / Źródła i emulatory / Biblioteka**.

Sprawdź wykryte źródła i konfigurację każdego emulatora. Zweryfikuj foldery ROM-ów, plik konfiguracji i zapisy; powrót do automatycznego przywraca wykrywanie. W szczegółach ROM-u wybieraj tylko dostępne składniki. ROM, stan i zapis gry to różne rzeczy. Dla Switch/Eden sprawdź profil odbiorcy.
