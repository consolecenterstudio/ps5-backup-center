# Primeiros passos

![PS5 Backup Center](assets/brand-preserve.png)

TV / Web: **Configurações / Dispositivos**.

1. Na TV, abrir Configurações → Dispositivos. Consultar o endereço e o código de seis dígitos exibidos. Usar computador ou telefone na mesma rede.

2. Abrir o endereço da própria console. Informar o código atual e um nome reconhecível e escolher Parear. O código muda ao reiniciar o motor; dispositivos já pareados continuam pareados.

3. Abrir Biblioteca. Filtrar por conteúdo, emulador ou local, ou buscar um título. Abrir a ficha e conferir componentes e destino antes de operar.

4. Usar Tarefas para acompanhar progresso e resultados. Fechar a página ou a interface de TV não é parar o motor ou desligar o console.

Se falhar, conferir endereço atual, console, motor e rede. Ausência de confirmação não é sucesso. Não publicar códigos, tokens, IDs de conta ou endereços privados ao pedir suporte.
