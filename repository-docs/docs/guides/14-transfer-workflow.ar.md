# نسخ لعبة كاملة أو نقلها

![PS5 Backup Center](assets/brand-preserve.png)

النسخ يبقي المصدر؛ النقل يحذفه بعد التحقق من الوجهة. الضغط وحده لا يحمي الحفظ النشط.

## مكان الوصول

TV / Web: **النقل → المهام**.

## الخطوات

1. أغلق اللعبة على الوحدتين. اختر المصدر والوجهة منفصلين وتحقق من المساحة والمكونات وتوافق التنسيق والنظام وSDK والتعديلات التوافقية.
2. تحقق من قرص وحساب المستلم قبل التأكيد. انتظر اكتمال التحقق والتثبيت؛ وصول النسخ إلى 100٪ لا ينهي جميع المراحل.

## عند الانقطاع

حدث مكتبة المستلم واختبر تشغيل اللعبة عندما يناسب. إذا فشل النقل فلا تحذف المصدر يدوياً. استعادة الوحدة كاملة ميزة مستقبلية أخرى.
