# Risolvere problemi

![PS5 Backup Center](assets/brand-web.png)

TV / Web: **Attività / Diagnostica e info**.

In caso di interruzione ricollega la stessa destinazione e controlla l’attività esistente prima di crearne un’altra. Non cancellare file parziali né rinominare cartelle per forzare un tentativo. Conserva una copia indipendente dei dati importanti.

Se perdi la connessione controlla console, motore, indirizzo attuale e attività prima di ripetere. Non pubblicare codici o token e non esporre la porta locale a Internet.

Se il risultato non è quello previsto, smetti di giocare per evitare nuovi salvataggi automatici. Trova copia di sicurezza e versione originale prima di ripristinare ancora. L’adattamento dell’account non converte partite incompatibili tra giochi, regioni o generazioni.
