# ブラウザーとバックグラウンドエンジンを使う

![PS5 Backup Center](assets/brand-web.png)

テレビとブラウザーは同じエンジンのクライアントです。画面を閉じてもエンジンは自動停止しません。本体の電源を切ることとは異なります。

## 操作する場所

TV / Web: **設定 → デバイス → ライブラリー → タスク**.

## 手順

1. 本体の現在のアドレスとペアリングコードを読みます。同じローカルネットワークで開き、6桁のコードと分かりやすい名前を入力します。ペアリングはデータと操作へのアクセスを許可します。
2. ライブラリとタスクを開きます。実行前に保存先と範囲、その後に最終結果を確認します。ペアリング済みのブラウザーはアクセスを保持する場合があります。

## 中断した場合

切断時は本体、エンジン、現在のアドレス、既存のタスクを確認してから再試行します。コードやトークンを公開せず、ローカルポートをインターネットに公開しないでください。
