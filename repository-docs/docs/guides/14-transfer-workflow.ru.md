# Копирование или перенос целой игры

![PS5 Backup Center](assets/brand-preserve.png)

Копирование сохраняет источник; перенос удаляет его после проверки цели. Сжатие само по себе не защищает активное сохранение.

## Где найти

TV / Web: **Передачи → Задачи**.

## Действия

1. Закройте игру на обеих консолях. Выберите источник и цель отдельно; проверьте место, компоненты и совместимость формата, системы, SDK и бэкпорта.
2. Проверьте диск и получающую запись перед подтверждением. Дождитесь проверки и установки; 100% копирования не завершает все этапы.

## При прерывании

Обновите библиотеку получателя и проверьте запуск игры при возможности. При ошибке переноса не удаляйте источник вручную. Полное восстановление консоли — другая будущая функция.
