# Résoudre un problème

![PS5 Backup Center](assets/brand-web.png)

Identifier un problème en conservant les éléments utiles.

## Où le trouver

Télé : Tâches ; Paramètres › Diagnostic et à propos. L1/R1 change les onglets ; ouvrez la roue dentée pour Paramètres.

Web : mêmes espaces dans la navigation du navigateur associé ; utilisez les boutons et cases à cocher.

## Étapes

1. Notez versions de l’app et du moteur, action et message exact. Regardez Tâches avant de relancer pour éviter un doublon.
2. Distinguez interface télé fermée et moteur inaccessible ; vérifiez adresse affichée et réseau local.
3. Pour le NAS, testez protocole, identifiants et droits du dossier ; les ports passifs FTP diffèrent du port de contrôle.
4. Pour Switch, vérifiez ftpd, adresse, port et export JKSV. Une Synchro bloquée sur lecture demande version et diagnostic avant relance.
5. Retirez ID, noms, adresses, machines, mots de passe, jetons et codes avant partage. Suivez le signalement privé pour la sécurité.

## Précautions

Fermez le jeu ou l’application concernée avant restauration, remplacement ou déplacement. Vérifiez compte, sens et destination ; lisez les confirmations et conservez une copie indépendante des données importantes. Les copies de sécurité et vérifications réduisent les risques sans constituer une garantie absolue.
