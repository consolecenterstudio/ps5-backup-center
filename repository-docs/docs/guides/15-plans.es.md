# Programar un plan de copia

![PS5 Backup Center](assets/brand-organize.png)

Un plan repite las opciones de una copia. No es la futura sincronización automática al cerrar un juego.

## Dónde encontrarlo

TV / Web: **Tareas → Planes programados…**.

## Pasos

1. Abre el editor de planes en tareas o desde la ficha. Elige plantilla o plan personalizado, nombre, juegos o reglas, componentes, destino, horario y número de versiones.
2. Comprueba cómo se incluyen juegos nuevos y que el destino esté accesible. Guarda y vuelve a abrir el plan. Si procede, ejecútalo a demanda y revisa la tarea y la copia creada.

## Si se interrumpe

Pausar un plan y cancelar una ejecución son decisiones distintas. Revisa errores y tareas existentes antes de repetir. La rotación no sustituye una copia independiente.
