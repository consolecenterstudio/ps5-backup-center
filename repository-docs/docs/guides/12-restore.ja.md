# 選んだセーブを復元する

![PS5 Backup Center](assets/brand-preserve.png)

復元は保存済みのコピーを選んだアカウントの現在の進行状況に戻します。ゲームのインストールや本体全体の復元とは異なります。

## 操作する場所

TV / Web: **セーブデータ → すべてのバージョン → 復元する**. **タスク**.

## 手順

1. ゲームを終了し、現在の進行状況の独立したコピーを保管します。日付だけでなく内容と進行状況でバージョンを比較します。
2. 選んだコピーを開いて復元を選びます。プロフィール名が似ていても、受信するアカウントを確認します。
3. 検証結果と、置き換えるセーブの安全用コピーの説明を読みます。検証に失敗したら停止してメッセージを記録し、対象が違えばキャンセルします。
4. 確認してタスクの最終結果を待ちます。受信アカウントの進行状況を確認し、適切なタイミングでゲーム内でも確認します。

## 中断した場合

結果が予想と違う場合は、新しい自動セーブを避けるためプレイを止めます。再び復元する前に安全用コピーと元のバージョンを確認してください。アカウントの調整は、異なるゲーム、地域、世代の非互換セーブを変換するものではありません。
