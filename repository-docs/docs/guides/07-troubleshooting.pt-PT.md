# Resolver problemas

![PS5 Backup Center](assets/brand-web.png)

TV / Web: **Tarefas / Diagnóstico e acerca de**.

Se houver interrupção, volte a ligar o mesmo destino e examine a tarefa existente antes de criar outra. Não elimine ficheiros parciais nem mude o nome das pastas para forçar nova tentativa. Mantenha uma cópia independente dos dados importantes.

Se desligar, confirme consola, motor e endereço atual; examine a tarefa antes de repetir. Não publique códigos ou tokens nem exponha a porta local à Internet.

Se o resultado não for o esperado, pare de jogar para evitar novas gravações automáticas. Localize a cópia de segurança e a versão original antes de restaurar novamente. A adaptação dos identificadores não converte partidas incompatíveis entre jogos, regiões ou gerações.
