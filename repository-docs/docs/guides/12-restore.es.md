# Restaurar una partida elegida

![PS5 Backup Center](assets/brand-preserve.png)

Restaurar convierte una copia almacenada en la partida activa del usuario elegido. No instala el juego ni restaura toda la consola.

## Dónde encontrarlo

TV / Web: **Partidas → Todas las versiones → Restaurar**. **Tareas**.

## Pasos

1. Cierra el juego y conserva una copia independiente de la partida actual. Compara las versiones por contenido y progreso, no solo por fecha.
2. Abre la copia elegida y selecciona Restaurar. Comprueba el usuario de destino aunque tenga el mismo nombre que otro perfil.
3. Lee la verificación y la copia de seguridad propuesta para la partida que se sustituirá. Si la verificación falla, detente y guarda el mensaje; cancela si el destino es incorrecto.
4. Confirma y sigue la tarea hasta el resultado final. Comprueba la partida del usuario receptor y, cuando corresponda, ábrela en el juego.

## Si se interrumpe

Si el resultado no es el esperado, deja de jugar para evitar nuevas escrituras automáticas. Localiza la copia de seguridad y la versión original antes de restaurar de nuevo. La adaptación de identificadores no convierte partidas incompatibles entre juegos, regiones o generaciones.
