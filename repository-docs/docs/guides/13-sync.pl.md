# Wybór rodzaju synchronizacji

![PS5 Backup Center](assets/brand-link.png)

Przechowywane kopie i aktywne zapisy to różne rzeczy. Całe gry obsługuje się przez transfery. Szybkie przygotowanie planu nie oznacza ciągłej automatycznej synchronizacji.

## Gdzie znaleźć

TV / Web: **Synchro** → **Zapisy / Aktywne postępy / Aplikacje / DLC / Ustawienia**.

## Kroki

1. Wybierz urządzenie i sekcję: kopie, aktywne zapisy, aplikacje, ustawienia lub DLC. Zacznij od małego, jednoznacznego wyboru.
2. Dla kopii sprawdź gry, wersje i cel. Dla aktywnych zapisów sprawdź konta po obu stronach, kierunek i konflikty; zamknij grę na obu konsolach.
3. Dla aplikacji zamknij aplikację odbiorcy i porównaj wersję oraz odcisk. Ten sam numer z innymi plikami wymaga decyzji. Wybierz ustawienia zgodnie z dostępnym profilem.
4. Sprawdź zmiany i potwierdź tylko zamierzone działania. Śledź zadanie do wyniku i odśwież porównanie przed ponowieniem.

## Więcej informacji

NAS może przechowywać aktywne zapisy i aplikacje jako repozytorium; nie uruchamia gier. DLC i ustawienia pozostają operacjami między PS5. Dla Switch/Eden sprawdź grę i profil, przygotuj JKSV oraz ftpd i zakończ import JKSV przy wysyłaniu na Switch. Switch ↔ Switch i instalacja DLC PS5 są planowane; lista pakietów nie jest instalacją.
