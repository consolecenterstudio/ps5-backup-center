# 開始使用

![PS5 Backup Center](assets/brand-preserve.png)

TV / Web: **設定 / 裝置**.

1. 在電視上開啟設定 → 裝置，查看顯示的位址和六位配對碼。使用同一網路的電腦或手機。

2. 開啟自己主機顯示的位址，輸入目前配對碼和易辨識的裝置名稱，然後選擇配對。引擎重啟會更換配對碼，已配對裝置仍保留配對。

3. 開啟資料庫，依內容、模擬器或位置篩選，或搜尋標題。操作前開啟詳細資料卡，檢查可用元件和目標位置。

4. 在任務中查看進度和結果。關閉網頁或電視介面不同於停止引擎或關閉主機。

連線失敗時檢查目前位址、主機、引擎及網路。缺少確認不代表成功。公開求助時不要發布配對碼、權杖、帳戶識別或私人網路位址。
