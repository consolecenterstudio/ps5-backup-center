# المحاكيات وملفات ROM

![PS5 Backup Center](assets/brand-web.png)

TV / Web: **الإعدادات / المصادر والمحاكيات / المكتبة**.

راجع المصادر المكتشفة وإعداد كل محاكي. تحقق من مجلدات ROM وملف الإعداد والحفظ؛ العودة للتلقائي تعيد الاكتشاف. اختر المكونات المعروضة فقط في تفاصيل ROM. ملف ROM والحالة وحفظ اللعبة أشياء مختلفة. تحقق من الملف الشخصي المستلم في Switch/Eden.
