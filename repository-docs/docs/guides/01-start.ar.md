# البدء

![PS5 Backup Center](assets/brand-preserve.png)

TV / Web: **الإعدادات / الأجهزة**.

1. على التلفاز افتح الإعدادات ← الأجهزة. اقرأ العنوان ورمز الاقتران المكون من ستة أرقام. استخدم حاسوبًا أو هاتفًا على الشبكة نفسها.

2. افتح العنوان الظاهر على جهازك، وأدخل الرمز الحالي واسمًا واضحًا للجهاز ثم اختر الاقتران. يتغير الرمز عند إعادة تشغيل المحرك؛ وتبقى الأجهزة المقترنة مقترنة.

3. افتح المكتبة وصفِّ المحتوى أو المحاكي أو الموقع أو ابحث عن عنوان. افتح البطاقة وراجع المكونات والوجهة قبل أي عملية.

4. تابع التقدم والنتائج في المهام. إغلاق الصفحة أو واجهة التلفاز يختلف عن إيقاف المحرك أو إطفاء الجهاز.

عند الفشل تحقق من العنوان الحالي والجهاز والمحرك والشبكة. غياب التأكيد لا يعني النجاح. لا تنشر رموز الاقتران أو التوكنات أو معرفات الحسابات أو العناوين الخاصة في طلبات الدعم العامة.
