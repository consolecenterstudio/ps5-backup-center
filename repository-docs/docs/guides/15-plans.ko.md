# 백업 계획 예약

![PS5 Backup Center](assets/brand-organize.png)

계획은 선택한 백업 설정을 반복합니다. 게임 종료 시 자동 동기화라는 예정 기능과는 다릅니다.

## 메뉴 위치

TV / Web: **작업 → 예약된 플랜…**.

## 단계

1. 작업 또는 게임 상세에서 계획 편집기를 엽니다. 템플릿이나 사용자 계획, 이름, 게임 또는 규칙, 구성 요소, 대상, 일정과 보관 버전 수를 선택합니다.
2. 새 게임의 포함 방식과 대상 연결을 확인합니다. 저장 후 다시 열어 점검하고 필요하면 한 번 실행해 작업과 생성된 사본을 확인합니다.

## 중단된 경우

계획 일시 중지와 한 번의 실행 취소는 다릅니다. 다시 실행하기 전에 오류와 기존 작업을 확인하세요. 버전 순환은 독립된 사본을 대체하지 못합니다.
