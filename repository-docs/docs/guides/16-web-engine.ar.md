# استخدام المتصفح والمحرك الخلفي

![PS5 Backup Center](assets/brand-web.png)

واجهة التلفاز والمتصفح عميلان للمحرك نفسه. إغلاق الواجهة لا يوقف المحرك تلقائياً؛ إطفاء الوحدة أمر آخر.

## مكان الوصول

TV / Web: **الإعدادات → الأجهزة → المكتبة → المهام**.

## الخطوات

1. اقرأ العنوان ورمز الاقتران الحاليين على الوحدة. افتح العنوان في الشبكة المحلية وأدخل الرمز ذي الست خانات واسماً واضحاً. الاقتران يمنح الوصول للبيانات والأوامر.
2. افتح المكتبة والمهام. تحقق من الوجهة والنطاق قبل التشغيل ثم النتيجة النهائية. قد يحتفظ المتصفح المقترن بالوصول.

## عند الانقطاع

عند الانقطاع افحص الوحدة والمحرك والعنوان الحالي والمهمة الموجودة قبل الإعادة. لا تنشر الرموز أو رموز الوصول ولا تعرض المنفذ المحلي للإنترنت.
