# 홈과 알림 센터

![PS5 Backup Center](assets/brand-organize.png)

홈은 알려진 사본이 없는 게임, 더 새로운 사본, 중복, 비교나 점검이 필요한 데이터, 기기 동기화와 진행 중인 작업을 안내합니다. 카드는 목록과 기기 상태에 따라 달라집니다.

카드를 열어 작업 전에 게임, 플레이어와 저장 위치를 확인합니다. 동기화 전에는 선택, 방향과 충돌을, 정리 전에는 남을 버전을 확인합니다. 작업의 최종 결과를 본 뒤 홈을 새로 고칩니다. 게임 미선택은 오류가 아니며 동기화 완료는 선택 범위를 뜻합니다. 아래로 내려 최근 게임, 미설치 게임의 저장 데이터, 외부 콘텐츠, 레트로와 앱도 확인하세요.
