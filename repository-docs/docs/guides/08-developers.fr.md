# Pour les développeurs

![PS5 Backup Center](assets/brand-web.png)

Retrouver architecture et références de contribution.

## Où le trouver

Télé : Paramètres › Diagnostic et à propos / Remerciements. L1/R1 change les onglets ; ouvrez la roue dentée pour Paramètres.

Web : mêmes espaces dans la navigation du navigateur associé ; utilisez les boutons et cases à cocher.

## Étapes

1. Le moteur sert API et web, gère scan, copie et journal des tâches ; télé et navigateur sont ses clients.
2. Lisez CONTRIBUTING pour compilation et outils ; une prévisualisation Mac ne prouve pas un fonctionnement sur console.
3. FEATURES porte la matrice télé/web ; PLAN les décisions ; changelog.json l’historique source.
4. Pour traduire, utilisez les catalogues i18n, conservez les paramètres et vérifiez encombrement, CJK et arabe. Prévoyez les deux interfaces.
5. Référence API générée, exemples authentifiés et vérification de reproductibilité restent des travaux distincts ; ce texte n’est pas un contrat API.

## Précautions

Fermez le jeu ou l’application concernée avant restauration, remplacement ou déplacement. Vérifiez compte, sens et destination ; lisez les confirmations et conservez une copie indépendante des données importantes. Les copies de sécurité et vérifications réduisent les risques sans constituer une garantie absolue.
