# الألعاب والنقل

![PS5 Backup Center](assets/brand-preserve.png)

TV / Web: **النقل / المهام**.

النسخ يبقي المصدر؛ النقل يحذفه بعد التحقق من الوجهة. الضغط وحده لا يحمي الحفظ النشط.

أغلق اللعبة على الوحدتين. اختر المصدر والوجهة منفصلين وتحقق من المساحة والمكونات وتوافق التنسيق والنظام وSDK والتعديلات التوافقية.

تحقق من قرص وحساب المستلم قبل التأكيد. انتظر اكتمال التحقق والتثبيت؛ وصول النسخ إلى 100٪ لا ينهي جميع المراحل.

حدث مكتبة المستلم واختبر تشغيل اللعبة عندما يناسب. إذا فشل النقل فلا تحذف المصدر يدوياً. استعادة الوحدة كاملة ميزة مستقبلية أخرى.
