# مقارنة النسخ وتنظيف المكررات

![PS5 Backup Center](assets/brand-organize.png)

التاريخ وحده لا يحدد التقدم الأبعد. حروف المحتوى تميز البيانات وليست ترتيباً للأفضلية.

## مكان الوصول

TV / Web: **ملفات الحفظ → كل الإصدارات**.

## الخطوات

1. افتح كل الإصدارات وتحقق من المواقع والحساب والحماية وانتظر المقارنة مع إغلاق اللعبة. تعذر قراءة التقدم لا يعني أن الحفظ فارغ.
2. راجع كل نسخة مقترحة للحذف وكل نسخة ستبقى. احتفظ بالإصدارات المهمة ونسخ اللاعبين الآخرين. ألغ الاختيار الخاطئ؛ الحذف يحتاج تثبيت التأكيد خمس ثوانٍ.

## عند الانقطاع

تحقق من سلة المحذوفات ومدتها حيث تتوفر. المحلية تستخدم 30 يوماً؛ لا تفترض الاستعادة نفسها على NAS. سلته ميزة مخططة.
