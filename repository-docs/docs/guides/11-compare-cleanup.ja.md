# コピーを比較して重複を整理する

![PS5 Backup Center](assets/brand-organize.png)

日付だけでは最も進んだセーブは分かりません。内容の文字はデータを区別するもので、順位ではありません。

## 操作する場所

TV / Web: **セーブデータ → すべてのバージョン**.

## 手順

1. すべてのバージョンを開き、場所、アカウント、保護を確認します。ゲームを終了して比較を待ちます。進行状況を読めなくても空のセーブとは限りません。
2. 削除候補と残るコピーを一つずつ確認します。重要なバージョンと他のプレイヤーのコピーを保持します。選択が違えばキャンセルし、削除は5秒の長押しで確認します。

## 中断した場合

利用できる場合はごみ箱と期限を確認します。ローカルは30日です。NASにも同じ復元を期待しないでください。NASのごみ箱は今後の予定です。
