# 恢复选定的存档

![PS5 Backup Center](assets/brand-preserve.png)

恢复会将已存储的副本写入所选账户的当前游戏进度。它不会安装游戏，也不是整台主机恢复。

## 入口

TV / Web: **存档 → 所有版本 → 恢复**. **任务**.

## 操作步骤

1. 关闭游戏并保留当前进度的独立副本。按内容和进度比较版本，不要只看日期。
2. 打开所选副本并选择恢复。即使用户名称相似，也要确认接收账户。
3. 阅读校验结果以及替换前进度的安全副本说明。校验失败时应停止并记录消息；目标不对则取消。
4. 确认后在任务中等待最终结果。检查接收账户的进度，并在适当时进入游戏验证。

## 中断后的处理

结果不符合预期时先停止游戏，避免新的自动存档。再次恢复前找到安全副本和原始版本。账户适配不会将不同游戏、地区或世代间不兼容的存档进行转换。
