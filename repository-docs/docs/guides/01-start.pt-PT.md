# Primeiros passos

![PS5 Backup Center](assets/brand-preserve.png)

TV / Web: **Definições / Dispositivos**.

1. Na TV, abrir Definições → Dispositivos. Consultar o endereço e o código de seis dígitos apresentados. Usar computador ou telefone na mesma rede.

2. Abrir o endereço da própria consola. Introduzir o código atual e um nome reconhecível e escolher Emparelhar. O código muda ao reiniciar o motor; os dispositivos já emparelhados continuam emparelhados.

3. Abrir Biblioteca. Filtrar por conteúdo, emulador ou localização, ou procurar um título. Abrir a ficha e verificar componentes e destino antes de operar.

4. Usar Tarefas para acompanhar progresso e resultados. Fechar a página ou a interface de TV não é parar o motor ou desligar a consola.

Se falhar, verificar endereço atual, consola, motor e rede. Ausência de confirmação não é sucesso. Não publicar códigos, tokens, IDs de conta ou endereços privados ao pedir apoio.
