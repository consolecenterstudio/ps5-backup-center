# Restaurar uma partida escolhida

![PS5 Backup Center](assets/brand-preserve.png)

Restaurar transforma uma cópia armazenada na partida ativa do usuário escolhido. Não instala o jogo nem restaura o console inteiro.

## Onde encontrar

TV / Web: **Saves → Todas as versões → Restaurar**. **Tarefas**.

## Etapas

1. Feche o jogo e mantenha uma cópia independente da partida atual. Compare versões por conteúdo e progresso, não apenas pela data.
2. Abra a cópia escolhida e selecione Restaurar. Confira o usuário de destino mesmo que tenha o mesmo nome de outro perfil.
3. Leia a verificação e a cópia de segurança proposta para a partida que será substituída. Se a verificação falhar, pare e registre a mensagem; cancele se o destino estiver errado.
4. Confirme e acompanhe a tarefa até o resultado final. Confira a partida do usuário receptor e, quando apropriado, abra-a no jogo.

## Se houver interrupção

Se o resultado não for o esperado, pare de jogar para evitar novos salvamentos automáticos. Localize a cópia de segurança e a versão original antes de restaurar novamente. A adaptação dos identificadores não converte partidas incompatíveis entre jogos, regiões ou gerações.
