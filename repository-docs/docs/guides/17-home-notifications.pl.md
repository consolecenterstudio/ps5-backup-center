# Ekran główny i centrum powiadomień

![PS5 Backup Center](assets/brand-organize.png)

Ekran główny proponuje działania: gry bez znanej kopii, nowsze kopie, duplikaty, dane do porównania lub sprawdzenia, synchronizację i bieżące zadania. Karty zależą od inwentarza i urządzeń.

Otwórz kartę i sprawdź grę, gracza i nośnik przed działaniem. Przed synchronizacją sprawdź wybór, kierunek i konflikty, a przed czyszczeniem pozostające wersje. Śledź wynik w zadaniach i odśwież ekran główny. Brak wybranych gier nie oznacza błędu; synchronizacja dotyczy wyboru. Przewijaj też ostatnie gry, zapisy bez zainstalowanej gry, treści zewnętrzne, retro i aplikacje.
