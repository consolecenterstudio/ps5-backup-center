# Jeux et transferts

![PS5 Backup Center](assets/brand-preserve.png)

Copier, déplacer et gérer jeux entiers et images.

## Où le trouver

Télé : Transferts ; Bibliothèque › fiche. L1/R1 change les onglets ; ouvrez la roue dentée pour Paramètres.

Web : mêmes espaces dans la navigation du navigateur associé ; utilisez les boutons et cases à cocher.

## Étapes

1. Choisissez DEPUIS et VERS puis les titres. Vérifiez disque réel, espace et compatibilité destinataire.

2. Copier conserve la source ; Déplacer la retire après vérification. Examinez le format : dossier, .exfat ou .ffpfsc compressé.
3. Les outils d’image proposent compression, extraction, vérification et test de lecture. Lisez les effets avant une écriture.
4. Vers une PS5, examinez système, SDK, backport et compte destinataire. Une indication de compatibilité ne garantit pas le lancement.
5. Pour la sauvegarde complète, choisissez catégories et destination, vérifiez les tailles et suivez Tâches. L’assistant de restauration complète reste à venir.

## Précautions

Fermez le jeu ou l’application concernée avant restauration, remplacement ou déplacement. Vérifiez compte, sens et destination ; lisez les confirmations et conservez une copie indépendante des données importantes. Les copies de sécurité et vérifications réduisent les risques sans constituer une garantie absolue.
