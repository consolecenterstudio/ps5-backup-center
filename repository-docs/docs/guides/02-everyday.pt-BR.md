# Backups e restauração no dia a dia

![PS5 Backup Center](assets/brand-organize.png)

TV / Web: **Biblioteca / Progresso / Saves / Tarefas**.

Uma cópia armazenada não é a partida ativa e não inclui necessariamente o jogo. Escolha os componentes que deseja proteger.

1. Feche o jogo. Confira jogador, título, identidade do disco de destino e espaço livre.
2. Abra os detalhes e selecione partida, jogo, DLC, estado ou configuração conforme os componentes disponíveis. Revise o resumo antes de iniciar.
3. Acompanhe Tarefas até o resultado final; enviar a solicitação não significa concluir o backup. Leia erros e itens ignorados.
4. Em Backups, abra as versões do jogo e confira data, localização e componentes da nova cópia.

Restaurar transforma uma cópia armazenada na partida ativa do usuário escolhido. Não instala o jogo nem restaura o console inteiro.

Se o resultado não for o esperado, pare de jogar para evitar novos salvamentos automáticos. Localize a cópia de segurança e a versão original antes de restaurar novamente. A adaptação dos identificadores não converte partidas incompatíveis entre jogos, regiões ou gerações.
