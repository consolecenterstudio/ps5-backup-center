# 遊戲與傳輸

![PS5 Backup Center](assets/brand-preserve.png)

TV / Web: **傳輸 / 工作**.

複製保留來源；移動在目標驗證後刪除來源。壓縮遊戲本身不會保護目前存檔。

在兩台主機上關閉遊戲。分別選擇來源和目標，檢查空間、元件以及格式、系統、SDK與移植修補相容性。

確認前檢查接收磁碟和帳戶。等待驗證與安裝完成；複製100%不代表所有階段完成。

重新整理接收端遊戲庫，適當時測試遊戲。移動失敗時不要手動刪除來源。整機還原是另一項未來功能。
