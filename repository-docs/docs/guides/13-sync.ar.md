# اختيار نوع المزامنة المناسب

![PS5 Backup Center](assets/brand-link.png)

النسخ المخزنة وملفات الحفظ النشطة نوعان مختلفان. تعالج الألعاب الكاملة عبر النقل. إعداد الخطط بسرعة لا يعني مزامنة تلقائية مستمرة.

## مكان الوصول

TV / Web: **المزامنة** → **ملفات الحفظ / تقدّم اللعب الحالي / التطبيقات / DLC / الإعدادات**.

## الخطوات

1. اختر الجهاز ثم القسم: النسخ أو الحفظ النشط أو التطبيقات أو الإعدادات أو المحتوى الإضافي. ابدأ باختيار صغير وصريح.
2. للنسخ، تحقق من الألعاب والإصدارات والوجهة. للحفظ النشط، تحقق من الحسابين والاتجاه والتعارضات وأغلق اللعبة على الوحدتين.
3. للتطبيقات، أغلق التطبيق المستلم وقارن الإصدار والبصمة. الإصدار نفسه بملفات مختلفة يحتاج قراراً. اختر نطاق الإعدادات حسب الملف التعريفي المتاح.
4. اقرأ التغييرات وأكد العمليات المقصودة فقط. تابع نتيجة المهمة وحدث المقارنة قبل إعادة المحاولة.

## معلومات إضافية

يمكن أن يكون NAS مستودعاً للحفظ النشط والتطبيقات لكنه لا يشغل الألعاب. يبقى المحتوى الإضافي والإعدادات مسارين بين PS5. في Switch/Eden تحقق من اللعبة والملف الشخصي وجهز JKSV وftpd وأكمل استيراد JKSV عند الإرسال إلى Switch. المزامنة بين Switch وتثبيت محتوى PS5 الإضافي مخططان؛ قائمة الحزم ليست تثبيتاً.
