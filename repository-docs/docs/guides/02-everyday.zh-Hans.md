# 日常备份与恢复

![PS5 Backup Center](assets/brand-organize.png)

TV / Web: **游戏库 / 游戏进度 / 存档 / 任务**.

已存储的副本不是当前可玩的存档，也不一定包含游戏本体。请明确选择需要保护的组件。

1. 关闭游戏，确认玩家、游戏、目标磁盘的身份及可用空间。
2. 打开详情，从提供的组件中选择存档、游戏、DLC、即时存档或配置。开始前检查摘要。
3. 在任务中等待最终结果。提交请求不等于备份完成，请阅读错误和跳过项目。
4. 在备份页面打开游戏的版本列表，检查新副本的日期、位置和组件。

恢复会将已存储的副本写入所选账户的当前游戏进度。它不会安装游戏，也不是整台主机恢复。

结果不符合预期时先停止游戏，避免新的自动存档。再次恢复前找到安全副本和原始版本。账户适配不会将不同游戏、地区或世代间不兼容的存档进行转换。
