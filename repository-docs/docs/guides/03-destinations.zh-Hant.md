# 目標位置與已配對主機

![PS5 Backup Center](assets/brand-link.png)

TV / Web: **裝置 / 同步**.

在裝置頁面新增NAS或主機，儲存前核對身分。NAS需選擇支援的協定、測試連線並選定資料夾。兩台PS5之間確認配對碼；Switch需準備ftpd和JKSV匯出。FTP/FTPS可用，SMB仍在開發中。

NAS可作為目前存檔和應用程式的存放庫，但不會執行遊戲。DLC和設定仍是PS5之間的流程。Switch/Eden需確認遊戲與設定檔，準備JKSV和ftpd，傳回Switch後還要完成JKSV匯入。Switch ↔ Switch和PS5 DLC安裝屬於未來計畫；找到套件不等於安裝。
