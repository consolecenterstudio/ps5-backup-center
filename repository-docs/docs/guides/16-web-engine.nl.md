# Browser en achtergrondengine gebruiken

![PS5 Backup Center](assets/brand-web.png)

TV-interface en browser zijn clients van dezelfde engine. Een interface sluiten stopt de engine niet vanzelf; de console uitschakelen is iets anders.

## Waar je het vindt

TV / Web: **Instellingen → Apparaten → Bibliotheek → Taken**.

## Stappen

1. Lees het huidige adres en de koppelcode op de console. Open het adres in het lokale netwerk en vul de zescijferige code en herkenbare naam in. Koppeling geeft toegang tot gegevens en opdrachten.
2. Open bibliotheek en taken. Controleer doel en omvang voordat je start en lees het eindresultaat. Een gekoppelde browser kan toegang behouden.

## Bij onderbreking

Controleer bij verbindingsverlies console, engine, huidig adres en bestaande taak voor herhaling. Publiceer geen codes of tokens en stel de lokale poort niet bloot aan internet.
