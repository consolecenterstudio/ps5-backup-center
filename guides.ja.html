はじめに

TV / Web: 設定 / デバイス.

  1. TVで設定 → デバイスを開き、表示されたアドレスと6桁のコードを確認します。同じネットワークのPCまたは電話を使います。

  2. 自分の本体に表示されたアドレスを開き、現在のコードと分かりやすいデバイス名を入力してペアリングします。エンジンの再起動でコードは変わりますが、登録済みデバイスは保持されます。

  3. ライブラリーを開き、内容、エミュレーター、場所で絞り込むかタイトルを検索します。操作前に詳細で構成要素と保存先を確認します。

  4. タスクで進捗と結果を確認します。ページやTV画面を閉じることは、エンジン停止や本体電源オフとは別です。

接続できない場合は現在のアドレス、本体、エンジン、ネットワークを確認します。確認がない状態を成功と扱わないでください。公開のサポート依頼にコード、トークン、アカウントID、私有アドレスを載せないでください。

日常のバックアップと復元

TV / Web: ライブラリー / プレイデータ / セーブデータ / タスク.

保存したコピーはプレイに使う現在のセーブとは別物で、ゲーム本体が含まれるとは限りません。保護する項目を選んでください。

  1. ゲームを終了し、プレイヤー、タイトル、保存先のディスクと空き容量を確認します。
  2. 詳細を開き、表示された項目からセーブ、ゲーム、DLC、ステート、設定を選びます。開始前に概要を確認します。
  3. タスクで最終結果まで確認します。依頼を送信しただけではバックアップ完了ではありません。エラーやスキップされた項目も読みます。
  4. バックアップでゲームのバージョン一覧を開き、新しいコピーの日付、場所、内容を確認します。

操作する場所

TV / Web: ライブラリー → プレイデータ. タスク.

手順

  1. ゲームを終了し、プレイヤー、タイトル、保存先のディスクと空き容量を確認します。

  4. バックアップでゲームのバージョン一覧を開き、新しいコピーの日付、場所、内容を確認します。

結果の確認

タスクが完了し、目的のバージョンが一覧に表示されることを確認します。ファイルの検証は、ゲームの将来のすべてのバージョンで復元したセーブが読める保証ではありません。

コピーを比較して重複を整理する

日付だけでは最も進んだセーブは分かりません。内容の文字はデータを区別するもので、順位ではありません。

操作する場所

TV / Web: セーブデータ → すべてのバージョン.

手順

  1. すべてのバージョンを開き、場所、アカウント、保護を確認します。ゲームを終了して比較を待ちます。進行状況を読めなくても空のセーブとは限りません。
  2. 削除候補と残るコピーを一つずつ確認します。重要なバージョンと他のプレイヤーのコピーを保持します。選択が違えばキャンセルし、削除は5秒の長押しで確認します。

中断した場合

利用できる場合はごみ箱と期限を確認します。ローカルは30日です。NASにも同じ復元を期待しないでください。NASのごみ箱は今後の予定です。

選んだセーブを復元する

復元は保存済みのコピーを選んだアカウントの現在の進行状況に戻します。ゲームのインストールや本体全体の復元とは異なります。

操作する場所

TV / Web: セーブデータ → すべてのバージョン → 復元する. タスク.

手順

  1. ゲームを終了し、現在の進行状況の独立したコピーを保管します。日付だけでなく内容と進行状況でバージョンを比較します。
  2. 選んだコピーを開いて復元を選びます。プロフィール名が似ていても、受信するアカウントを確認します。
  3. 検証結果と、置き換えるセーブの安全用コピーの説明を読みます。検証に失敗したら停止してメッセージを記録し、対象が違えばキャンセルします。
  4. 確認してタスクの最終結果を待ちます。受信アカウントの進行状況を確認し、適切なタイミングでゲーム内でも確認します。

中断した場合

結果が予想と違う場合は、新しい自動セーブを避けるためプレイを止めます。再び復元する前に安全用コピーと元のバージョンを確認してください。アカウントの調整は、異なるゲーム、地域、世代の非互換セーブを変換するものではありません。

操作する場所

TV / Web: 同期 → セーブデータ / 現在のプレイデータ / アプリ / DLC / 設定.

手順

トラブルシューティング

TV / Web: タスク / 診断と情報.

中断した場合は同じ保存先を再接続し、新しいタスクを作る前に既存のタスクを確認します。再試行を強制するために途中のファイルを削除したりフォルダー名を変えたりしないでください。重要なデータは独立したコピーも保管します。

切断時は本体、エンジン、現在のアドレス、既存のタスクを確認してから再試行します。コードやトークンを公開せず、ローカルポートをインターネットに公開しないでください。

結果が予想と違う場合は、新しい自動セーブを避けるためプレイを止めます。再び復元する前に安全用コピーと元のバージョンを確認してください。アカウントの調整は、異なるゲーム、地域、世代の非互換セーブを変換するものではありません。
