开始使用

TV / Web: 设置 / 设备.

  1. 在电视上打开设置 → 设备，查看显示的地址和六位配对码。使用同一网络的电脑或手机。

  2. 打开自己主机显示的地址，输入当前配对码和易识别的设备名称，然后选择配对。引擎重启会更换配对码，已配对设备仍保留配对。

  3. 打开资料库，按内容、模拟器或位置筛选，或搜索标题。操作前打开详情卡，检查可用组件和目标位置。

  4. 在任务中查看进度和结果。关闭网页或电视界面不同于停止引擎或关闭主机。

连接失败时检查当前地址、主机、引擎及网络。缺少确认不代表成功。公开求助时不要发布配对码、令牌、账户标识或私人网络地址。

主页与通知中心

主页会提出操作建议：没有已知副本的游戏、更新的副本、重复项、待比较或检查内容、设备同步及进行中的任务。卡片随清单和设备状态变化。

操作前打开卡片，确认游戏、玩家和存储位置。同步前检查选择、方向和冲突；清理前检查将保留的版本。在任务中查看最终结果，再回主页刷新状态。未选择游戏不是错误，同步完成仅针对已选范围。继续向下滚动可查看最近游戏、未安装游戏的存档、外部内容、怀旧平台和应用。

日常备份与恢复

TV / Web: 游戏库 / 游戏进度 / 存档 / 任务.

已存储的副本不是当前可玩的存档，也不一定包含游戏本体。请明确选择需要保护的组件。

  1. 关闭游戏，确认玩家、游戏、目标磁盘的身份及可用空间。
  2. 打开详情，从提供的组件中选择存档、游戏、DLC、即时存档或配置。开始前检查摘要。
  3. 在任务中等待最终结果。提交请求不等于备份完成，请阅读错误和跳过项目。
  4. 在备份页面打开游戏的版本列表，检查新副本的日期、位置和组件。

恢复会将已存储的副本写入所选账户的当前游戏进度。它不会安装游戏，也不是整台主机恢复。

创建并检查备份

已存储的副本不是当前可玩的存档，也不一定包含游戏本体。请明确选择需要保护的组件。

入口

TV / Web: 游戏库 → 游戏进度. 任务.

操作步骤

  1. 关闭游戏，确认玩家、游戏、目标磁盘的身份及可用空间。
  2. 打开详情，从提供的组件中选择存档、游戏、DLC、即时存档或配置。开始前检查摘要。
  3. 在任务中等待最终结果。提交请求不等于备份完成，请阅读错误和跳过项目。
  4. 在备份页面打开游戏的版本列表，检查新副本的日期、位置和组件。

检查结果

任务应显示完成，预期版本也应出现在列表中。文件校验并不保证游戏的所有未来版本都能读取恢复后的存档。

中断后的处理

操作中断后，重新连接同一目标并先检查现有任务，再决定是否创建新任务。不要为强行重试而删除部分文件或重命名文件夹。为重要数据保留独立副本。

比较副本并清理重复项

日期不能单独说明哪份进度最靠前。内容字母区分不同数据，不代表好坏排名。

入口

TV / Web: 存档 → 所有版本.

操作步骤

  1. 打开所有版本，检查位置、账户和保护状态，在游戏关闭时等待比较。无法读取进度并不表示存档为空。
  2. 检查每份待删除与保留的副本。保留重要版本及其他玩家的副本。选择不对则取消；删除需要按住确认五秒。

中断后的处理

在支持的位置查看回收站和期限。本地回收站为30天；不要假定NAS有相同恢复能力。NAS回收站属于未来功能。

恢复选定的存档

恢复会将已存储的副本写入所选账户的当前游戏进度。它不会安装游戏，也不是整台主机恢复。

入口

TV / Web: 存档 → 所有版本 → 恢复. 任务.

操作步骤

  1. 关闭游戏并保留当前进度的独立副本。按内容和进度比较版本，不要只看日期。
  2. 打开所选副本并选择恢复。即使用户名称相似，也要确认接收账户。
  3. 阅读校验结果以及替换前进度的安全副本说明。校验失败时应停止并记录消息；目标不对则取消。
  4. 确认后在任务中等待最终结果。检查接收账户的进度，并在适当时进入游戏验证。

中断后的处理

结果不符合预期时先停止游戏，避免新的自动存档。再次恢复前找到安全副本和原始版本。账户适配不会将不同游戏、地区或世代间不兼容的存档进行转换。

安排备份计划

计划重复执行选定的备份设置，不是未来的游戏关闭时自动同步。

入口

TV / Web: 任务 → 定时计划….

操作步骤

  1. 从任务或游戏详情打开计划编辑器。选择模板或自定义计划、名称、游戏或规则、组件、目标、时间及保留版本数。
  2. 检查新游戏如何纳入计划以及目标是否可达。保存后重新打开核对。适当时手动运行一次，检查任务和新副本。

中断后的处理

暂停计划与取消一次执行不同。重试前检查错误及已有任务。轮换不能替代独立副本。

选择正确的同步方式

已存储副本与当前游戏存档不同。完整游戏通过传输管理。快速准备的计划不等于持续自动同步。

入口

TV / Web: 同步 → 存档 / 当前游戏进度 / 应用 / DLC / 设置.

操作步骤

  1. 先选择设备，再选择副本、当前存档、应用、设置或DLC。先从少量明确选择的项目开始。
  2. 同步副本时检查游戏、版本和目标。同步当前存档时检查两端账户、方向和冲突，并在两台主机上关闭游戏。
  3. 同步应用前关闭接收端应用，比较版本与指纹。同版本但文件不同需要作出选择。根据可用应用配置选择设置范围。
  4. 阅读变更，仅确认符合意图的操作。在任务中等待结果，重试前刷新比较。

更多信息

NAS可作为当前存档和应用的存储仓库，但不会运行游戏。DLC和设置仍是PS5之间的流程。Switch/Eden需确认游戏与配置文件，准备JKSV和ftpd，传回Switch后还要完成JKSV导入。Switch ↔ Switch和PS5 DLC安装属于未来计划；发现软件包不等于安装。

复制或移动完整游戏

复制保留源文件；移动在目标校验后删除源文件。压缩游戏本身不会保护当前存档。

入口

TV / Web: 传输 → 任务.

操作步骤

  1. 在两台主机上关闭游戏。分别选择来源和目标，检查空间、组件以及格式、系统、SDK和移植补丁兼容性。
  2. 确认前检查接收磁盘和账户。等待校验与安装完成；复制100%不代表所有阶段完成。

中断后的处理

刷新接收端游戏库，适当时测试游戏。移动失败时不要手动删除来源。整机恢复是另一项未来功能。
